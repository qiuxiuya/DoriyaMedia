# DoriyaMedia

把自己的网盘和番剧变成一个能直接用的影视站:挂上 OpenList / WebDAV / 本地目录,扫描成媒体库,
自动刮削海报和简介;也能把 B 站正版番剧(带弹幕)建成库。浏览器和 iPhone 打开同一个地址就能看。

用 Go 写的单个二进制,前端嵌在里面;运行时只需要系统里有 `ffmpeg` / `ffprobe`(安装脚本会装好)。
**不做视频转码** —— 能直连就 302,客户端播不了的容器/音轨才现场转封装。

- 已经在用 OpenList / AList 管网盘?→ 建库扫描,手机上接着看
- 只想先看看有什么片?→ 用「文件」页浏览目录,点开就播,不用建库
- 想追 B 站番剧?→ 建一个 B 站番剧库,自动分季、带弹幕和字幕

---

## 它是什么 / 不是什么

| 是 | 不是 |
| --- | --- |
| 一个轻量的媒体库 + 播放网页 | 完整的 Emby / Jellyfin 替代品 |
| 网盘直连(302)优先,省服务器带宽 | 视频转码服务器(**已彻底移除转码**) |
| 面向 iOS Safari 的解码兼容层 | 支持所有浏览器 / 所有编码 |
| 单二进制,数据全在一个目录 | 集群、多机负载均衡 |

Emby 客户端可以连上来浏览和播放(协议兼容层),但没有转码、UDP 自动发现、Connect 或遥控。
细节见 [Emby 兼容说明](docs/emby-compatibility.md)。

## 5 分钟上手

### 1. 装起来

**Linux(Debian / Ubuntu),一行命令**:

```bash
curl -fsSL https://raw.githubusercontent.com/qiuxiuya/DoriyaMedia/main/scripts/install.sh | sudo bash
```

国内打不开 `raw.githubusercontent.com` 就用镜像(脚本内部也会自动回退下载源):

```bash
curl -fsSL https://ghfast.top/https://raw.githubusercontent.com/qiuxiuya/DoriyaMedia/main/scripts/install.sh | sudo bash
```

装完是一个 systemd 服务:程序在 `/usr/local/bin/doriyamedia`,数据在 `/opt/doriyamedia`,
日常用一个 `dm` 命令管理:

```bash
dm            # 菜单:更新 / 启停 / 日志 / 卸载
dm status     # 版本、端口、运行状态
```

> **从旧版升级**:旧版本的数据目录是 `/var/lib/doriyamedia`。重跑安装脚本或 `dm update` 时
> 会先停服务、把整个目录搬到 `/opt/doriyamedia`、同步改掉 `config.json` 里的 `data_dir` ——
> 媒体库、账号、播放进度都原样保留,不需要重扫。

**自己编译**:需要 Go 1.26+。前端产物已随仓库提交,所以**不需要 Node**。

```
CGO_ENABLED=0 go build -ldflags "-s -w" -o doriyamedia ./cmd/doriyamedia
./doriyamedia          # 前台运行,监听 0.0.0.0:5666,数据落在 ./data
```

运行环境只需要 **`ffmpeg` 和 `ffprobe`** 在 PATH 里(转封装、字幕转换都靠它);
系统包管理器装一下即可:`apt install ffmpeg` / `brew install ffmpeg`。

**Windows 上一键构建**(顺带构建前端,需要 pnpm):

```
scripts\build.ps1
.\doriyamedia.exe
```

更多安装选项(换端口、换目录、指定版本、卸载)、交叉编译与环境变量见 [部署与运维](docs/deploy.md)。

### 2. 建管理员

浏览器打开 `http://<服务器IP>:5666`,首次进入会要求创建管理员账号。

### 3. 加一个存储源

**设置 → 存储源 → 添加存储源**,四种类型:

| 类型 | 适合 | 播放方式 |
| --- | --- | --- |
| **OpenList / AList** | 天翼云盘、阿里云盘等网盘 | 能直连时 **302**,流量不经过服务器 |
| **WebDAV** | 坚果云、群晖、其它 WebDAV | 服务器代理,支持拖动 |
| **本地目录** | 服务器磁盘 / 已挂载的盘 | 服务器代理,支持拖动 |
| **B站番剧** | 正版番剧(PGC) | 服务端合流,带弹幕和字幕 |

最省服务器带宽的是 OpenList:填地址和后台的 token 即可,详见 [存储源](docs/storage-sources.md)。

### 4. 建媒体库并扫描

**设置 → 媒体库 → 展开表单**:选源、填路径(如 `/movies`)、选类型(电影 / 剧集)、
勾选刮削来源(建议 TMDB,番剧再加 Bangumi)→ 创建 → 点这个库的 **扫描**,等状态变成 `done`。

首页就有海报了,点进详情 → 播放。用 iPhone Safari 打开同一个地址即可直接播。

### 5. 让别人也能看

默认**允许自助注册**:把地址给别人,对方在登录页切到「注册」即可。普通用户共享全部媒体库,
但进不了设置后台。

不想让人随便注册:**设置 → 用户 → 注册与登录**,改成「需要审核」或「关闭注册」。
详见 [账号、注册与权限](docs/accounts.md)。

## 常见用法

### 只想看片,不想整理

用顶部导航的 **「文件」**:浏览任意存储源的目录,点视频就播。同样经过播放决策
(该 302 就 302,iOS 播不了的自动转封装),并且支持断点续播。

### 只建库,不刮削

媒体库不勾刮削来源也能扫,照样能播,只是没有海报和简介。之后想补,勾上再扫一次即可。

### 想把 B 站番剧建成库

**设置 → 存储源 → 类型选「B站番剧」→ 粘贴 Cookie → 添加**,然后建一个**剧集**库,
路径填 `/`(或 `/热门番剧`、`/我的追番`)→ 扫描。同一系列的多个季度会合并成一部剧。

Cookie 最好用**扫码登录**拿,浏览器里复制的 Cookie 会莫名其妙失效。
番剧的地区限制、港澳台代理、字幕、弹幕都在 [B 站番剧源](docs/bilibili.md)。

### 一个库想挂多个盘

设置 → 媒体库 → 编辑 → 「再加一个源」。同一个库里的多个源会一起扫描、合并成同一批剧集;
某部剧拆在两个盘上也没关系。移除某个源后重扫,只删它自己的条目。

## 为什么有的片子播不了

DoriyaMedia 用 **ffprobe 探测 + UA 判断** 来决定怎么播,规则只有四条:

| 决策 | 什么时候 | 代价 |
| --- | --- | --- |
| **302 直连** | 客户端原生支持,源能出直链(网盘) | 零 —— 流量不经过服务器 |
| **代理播放** | 客户端原生支持,但源要鉴权(本地 / WebDAV) | 走服务器带宽,支持 Range 拖动 |
| **HLS 转封装** | 视频能拷,但容器/编码标签/音轨不兼容 | 几乎零 CPU(`-c:v copy`),少量磁盘缓存 |
| **无法播放** | 视频编码本身解不了(AV1 / 10bit H.264 等) | 直接说明原因,**不转码** |

最常见的一句是「iOS 播不了 MKV」:Safari 根本不支持 MKV 容器,所以会自动转封装成 HLS;
而 AV1 这类编码连转封装都救不了,页面会直接告诉你播不了。

细节见 [播放:决策引擎、字幕、不转码](docs/playback.md)。

## 已知限制

- **不转码**:解不了的编码直接提示无法播放,只保留 302 / 代理 / HLS 转封装;
- iOS Safari 原生 HLS 播放时,外挂 VTT 字幕的 `<track>` 支持不稳定(建议用内嵌文字字幕);
- PGS / VobSub 图形字幕只能烧录(会重编码画面),不能作为文本字幕;
- 302 直连模式下多音轨通常由浏览器选第一条,HLS 模式下可切换;
- 所有用户共享全部媒体库,暂不支持按用户分配可见库;
- B 站源只做正版番剧(PGC),暂不支持普通投稿、直播、互动视频。
