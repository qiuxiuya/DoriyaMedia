# DoriyaMedia

把 OpenList / AList、WebDAV、本地目录和 B 站番剧整理成媒体库，在浏览器里观看，支持海报、字幕、弹幕和断点续播。

## 安装与更新

**Linux（Debian / Ubuntu）**：

```bash
curl -fsSL https://raw.githubusercontent.com/qiuxiuya/DoriyaMedia/main/scripts/install.sh | sudo bash
```

下载失败时使用镜像：

```bash
curl -fsSL https://ghfast.top/https://raw.githubusercontent.com/qiuxiuya/DoriyaMedia/main/scripts/install.sh | sudo bash
```

脚本会安装播放工具并启动服务。打开 `http://服务器IP:5666`，首次访问创建管理员；其他设备无法访问时检查防火墙端口。

需要自定义安装时，下载脚本后传入选项：

```bash
curl -fsSL https://raw.githubusercontent.com/qiuxiuya/DoriyaMedia/main/scripts/install.sh -o install.sh
sudo bash install.sh --port 8080 --data-dir /srv/doriyamedia
```

也可加 `--version 版本标签` 指定版本。

**手动安装**：从 [Releases](https://github.com/qiuxiuya/DoriyaMedia/releases) 下载对应平台压缩包，解压后运行 `./doriyamedia`（Windows 为 `doriyamedia.exe`）。需安装 `ffmpeg` 和 `ffprobe`，默认端口 5666，数据在当前工作目录的 `data` 中，每次从同一目录启动。

手动运行时可用 `./doriyamedia serve -port 8080 -listen 127.0.0.1` 修改端口并仅允许本机访问。工具路径可在「设置 → 系统 → 工具路径与性能」修改。

**服务管理**：Linux 脚本安装后使用：

```bash
dm           # 管理菜单
dm update    # 更新
dm status    # 查看状态
dm start     # 启动
dm stop      # 停止
dm restart   # 重启
dm log       # 查看日志
dm uninstall # 卸载，保留数据
```

手动安装时，停止程序、替换新版文件，再从原工作目录启动。

**备份恢复**：停止服务，复制整个数据目录，再启动。脚本安装默认为 `/opt/doriyamedia`；恢复时停服放回原位置，确保运行用户有读写权限。

## 开始使用

### 1. 添加存储源

进入「设置 → 存储源」，添加后点击「测试连接」。

| 类型 | 填写内容 |
| --- | --- |
| OpenList / AList | 服务地址和后台「设置 → 其他」中的令牌；允许游客访问时可留空 |
| WebDAV | WebDAV 地址、用户名、密码 |
| 本地目录 | 服务器绝对路径，例如 `/srv/media`，确保程序有读取权限 |
| B站番剧 | 添加后在源卡片点击「扫码登录」 |

OpenList / AList 应先挂载好存储，确认能够浏览和下载文件。本地目录需对程序运行用户可读，脚本安装的运行用户为 doriyamedia。

### 2. 创建媒体库

进入「设置 → 媒体库 → 展开表单」，填写名称，选择电影或剧集，再选择源和目录。多个目录可点「再加一个源」合并到同一库。

需要海报和简介时，在「设置 → 刮削与播放」配置来源，再在媒体库勾选：

| 来源 | 配置 |
| --- | --- |
| 本地 nfo | 使用已有 Kodi 格式 nfo 和海报，无需密钥 |
| TMDB | 填 API Key 或读访问令牌，点击「测试连接」 |
| Bangumi | 适合番剧，公开数据可不填令牌，点击「测试连接」 |

连接失败时检查服务器网络，按需配置代理。不勾刮削来源也能扫描和播放。

### 3. 扫描并观看

创建后点击「全量扫描」，完成后从首页播放。新增文件或修改目录后再次扫描；只更新部分内容可用「按路径扫描」。不想建库时，直接在「文件」页打开视频。

剧集建议按「剧名 / Season 1 / 剧名.S01E01.mkv」整理，支持「第1季」「S01」等季目录。同一集的多版本可在季页面或播放器切换。

- **排除内容**：在媒体库设置文件名、文件夹排除规则，匹配文件夹时跳过其子目录；只影响入库。
- **修正识别**：在详情页点击「重新识别」或「按 ID 匹配」，填写 TMDB / Bangumi 条目 ID；图片丢失可重新扫描。
- **查缺字幕**：在媒体库点击「查缺字幕」，目前检查 BDRip / Blu-ray 等版本，跳过 WebRip。
- **搜索**：点击搜索入口或按 Ctrl / Cmd + K，查找影片、季和单集。

## B站番剧

仅支持正版番剧。源添加并扫码登录后，创建**剧集**库，目录填 `/`、`/热门番剧` 或 `/我的追番`，扫描即可。建议勾选 Bangumi 刮削。

已有 B 站源的剧集库时，站内搜索会显示「B 站片库 · 未入库」，点击结果可导入整个系列。

- **清晰度**：在播放器切换，实际可用档位和会员集权限取决于账号；只有低清晰度或试看时，检查登录和会员状态，尝试重新扫码或「续期」。
- **地区**：取决于服务器出口。在源中可单独填写 HTTP、SOCKS5 或支持的 Shadowsocks 代理，用「测试这个代理」检查地区与连通性。
- **地区筛选**：「只上架当前线路能播放的番剧」会隐藏受限季度；更换线路后重新扫描。
- **弹幕**：在控制栏开关并调整显示区域、透明度、字号和速度，桌面端按 D 切换。

番剧播放占用服务器带宽和封装缓存。请遵守平台条款与账号、会员及地区权限，勿公开分发番剧内容。

## 播放与字幕

默认自动选择直连、代理或转封装。OpenList 直连可节省服务器带宽；WebDAV、本地文件和转封装播放经过服务器。

出现 403、容器不兼容或有画面无声音时，可尝试「强制转封装」。**不提供视频编码兼容转码**，设备无法解码原视频时需换设备、浏览器或片源。

播放器会自动加载内嵌文本字幕和同目录匹配的外挂字幕，优先中文；可在字幕菜单切换或关闭。外挂字幕建议与视频同名，例如：

```text
示例.S01E01.mkv
示例.S01E01.zh-CN.ass
```

支持 SRT、ASS / SSA。复杂排版或图形字幕可在可用选项中选择「忠实排版（烧录）」；烧录会重编码画面，占用更多服务器资源。

桌面端单击播放 / 暂停、双击全屏；空格播放 / 暂停，左右方向键快退 / 快进，M 静音，F 全屏。触摸设备单击唤出控制条、双击播放 / 暂停，iOS 以系统控件为准。全屏可用锁定按钮减少误触。

## 账号与站点

**账号管理**：在「设置 → 用户 → 注册与登录」选择开放注册（默认）、需要审核或关闭注册。管理员可添加、审核、禁用账号、调整角色和重置密码。所有用户共享媒体库，播放进度独立；删除用户会清除其记录，至少需保留一个可用管理员。

**个人设置**：「头像 → 账号设置」中可改名、改密和绑定邮箱。改密后其他设备需重新登录；忘记密码可通过已绑定邮箱找回，未绑定时联系管理员。

**邮件与验证**：在「设置 → 邮件与验证」填写 SMTP 和邮箱授权码，设置站点地址并测试发送成功后，再开启注册邮箱验证。Turnstile 需填写 Site Key / Secret Key，并确保浏览器和服务器可访问验证服务；若因此无法登录，可在配置文件中关闭 Turnstile 后重启。

**Bangumi 同步**：在账号设置中用 [Bangumi 个人令牌](https://next.bgm.tv/demo/access-token)连接，开启「播放到 90% 自动标记看过」。旧进度可点「补同步已看完剧集」；多季番剧需在各季详情绑定对应季的 Bangumi ID。

**站点外观**：打开「设置 → 站点外观 → 改登录页文案」，用工具栏调整文案、导航、布局和页脚，预览后点击「发布」。发布前为草稿，「恢复成内置文案」会清除自定义内容。

**文件浏览权限**：在「设置 → 系统 → 文件浏览」选择都可见、仅管理员可见或关闭。

## Emby客户端

在「设置 → 系统 → Emby 设置」启用后，客户端手动添加 `http://服务器IP:5666`，使用 DoriyaMedia 账号登录；要求路径时可尝试 `/emby`。服务器名称和图标在同处修改，媒体库封面在媒体库编辑中设置。

支持基本浏览、搜索、播放、文本字幕、进度、已看状态和收藏，兼容程度取决于客户端。客户端需能解码原视频；不支持自动发现、Emby Connect、遥控、直播或完整 Emby 管理后台。

开启 Turnstile 时无法通过 Emby 客户端登录。外网建议使用 HTTPS，反向代理需覆盖整个站点并保留请求头、查询参数和 Range。播放链接含访问凭据，请勿公开分享。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 无法访问站点 | 检查服务状态、地址、端口和防火墙 |
| 扫描提示路径不存在 | 到「文件」页确认目录，再修改媒体库路径 |
| 没有海报或简介 | 检查刮削来源、密钥及网络，在设置中测试连接 |
| 一直加载或缺少播放工具 | 检查源连接、ffmpeg / ffprobe 路径和服务日志 |
| 手机流量播放 403 | 尝试「强制转封装」 |
| 只有声音或编码不支持 | 换支持该编码的设备或片源 |
| 字幕缺失或排版异常 | 检查文件命名、字幕菜单，或尝试烧录 |
| B站列表缺失或地区受限 | 检查代理出口、地区筛选；遇到限流稍后重试 |
| Emby连接或播放异常 | 先在同一设备浏览器验证站点和影片，再检查账号状态、验证码及客户端解码能力 |
