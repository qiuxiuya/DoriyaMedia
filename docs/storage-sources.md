# 存储源:OpenList / WebDAV / 本地目录

存储源是「媒体从哪来」。一个源可以是网盘(经 OpenList)、WebDAV,或服务器上的本地目录;
B 站番剧是另一种源,单独见 [B 站番剧源](bilibili.md)。

在 **设置 → 存储源** 里添加。卡片上可以「编辑」「删除」「测试连接」,删除被媒体库引用的源需要确认。

## 1. OpenList / AList(云盘,可 302 直连)

1. 部署 [OpenList](https://github.com/OpenListTeam/OpenList),添加 **天翼云盘** 存储并填入账号
   (天翼云盘新版需要验证码/设备指纹,按 OpenList 文档操作即可),确认 OpenList 网页里能播放/下载;
2. 在 OpenList 后台 `设置 → 其他` 复制 **令牌(token)**;
3. DoriyaMedia → 设置 → 存储源 → 类型选 `OpenList / AList`:
   - 地址:`http://<openlist主机>:5244`
   - Token:粘贴上面的令牌(不填则要求该路径允许游客访问);
4. 建媒体库 → 扫描。

### 直连(302)的注意点

- 网盘直链一般**绑定出口 IP 和时效**。家里宽带下,服务器和手机走同一个公网出口,302 直连没问题;
  如果手机在外网(流量)、服务器在家,直链可能 403 —— 播放器里点 **强制转封装** 即可
  (转封装模式下由服务器拉流,IP 与取链时一致,总是可用)。
- 若 OpenList 对该存储设置了"代理",`fs/get` 返回的是 OpenList 自己的 `/p` 链接,同样能 302。
- 想少占服务器带宽,就用 OpenList 源:能直连时播放器直接从网盘拉流,服务器只签发一个跳转。

## 2. WebDAV

填地址、用户名、密码即可。WebDAV 源的直链通常需要鉴权头,浏览器拿不到,所以 DoriyaMedia
对 WebDAV 一律走服务器代理(支持 Range 拖动)。想白嫖 302 直连,请用 OpenList 源。

## 3. 本地目录

填服务器上的**绝对路径**(例如 `/srv/media`),适合 NAS 或已经挂载好的磁盘。
本地文件同样走服务器代理播放,支持 Range 拖动。

> 本地路径必须是 DoriyaMedia 进程**能读到**的目录:systemd 部署时运行用户是 `doriyamedia`,
> 记得给它读权限(`chmod`/`chown` 或 ACL)。

## 4. 一个媒体库可以挂多个源

同一部剧拆在两个网盘、番剧在云端而字幕在某台机器上,都可以放进同一个库:

```
设置 → 媒体库 → 展开表单 → 存储源与路径:选一个源填一个路径 → 「再加一个源」
扫描时会把它们一起扫,合并成同一批剧集与电影(同一部剧出现在两个源也能归到一部)
```

- **文件按"来源 + 路径"认身份**:同一个路径出现在两个源里是两个不同的文件,不会互相顶掉;
- **移除某个源之后重扫,只删它自己的条目**,库里其它源的剧和观看进度不受影响;
- **某个源这次没读到(网络失败、盘没挂上),它的条目会被原样保留** —— 读不出来不等于文件没了。
  扫描日志里会明确写出「部分源读取失败(不清理这些源)」;
- 删掉一个**源**时,只要这个库还挂着别的源,库本身会留着(它的"首个源"自动换成剩下的那个);
- 剧集级的本地 nfo/海报按**文件所在的那个源**去找,不再假定库的首个源。

## 5. 扫描排除

每个媒体库可以单独配置:

- **扫描排除(文件名)**:发布附带物、预览、菜单之类。命中就不导入、不刮削、不出卡片;
- **扫描排除(文件夹)**:目录名命中就整棵跳过,任意深度都生效(适合 `特典` / `Extras` / `Sample`)。

两者都支持 `/…/` 正则,例如 `/(?i)^\[pv\d+\]$/`、`/^(CD|DVD)\d+$/`。

两者默认都**为空** —— 哪些词算"不是正片"取决于你的收藏,猜错会静默丢掉整部剧。
全局默认在 **设置 → 系统 → 工具路径与性能** 里(`config.json` 的
`exclude_keywords` / `exclude_folders`);库级列表选「跟随全局」就继承,单独设一份则完全替换全局那份。

被排除的文件**在「文件」浏览器里仍然能播** —— 排除只影响入库。
