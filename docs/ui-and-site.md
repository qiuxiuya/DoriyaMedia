# 界面、搜索与站点外观

前端是 Vue3 + Vite 的单页应用,整体按流媒体网站的观感做(参考 Netflix / Plex / MUBI 的暗色剧场风格)。

## 1. 导航与页面

顶部导航:**首页 / 电影 / 剧集 / 追番 / 文件 / 媒体库下拉**;管理员多一个 **设置**。
窄屏(<900px)自动切换为底部标签栏,并适配 iPhone 安全区。
`⌘/Ctrl + K` 呼出跨媒体库搜索面板。

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 首页 | `/` | Hero 剧场 + 横向影轨 |
| 电影 / 剧集 | `/library/:id` | 某个媒体库的列表 |
| 详情 | `/item/:id` | 剧集条目、重新识别、Bangumi ID 匹配 |
| 季页面 | `/season/:id` | 每集列表、每集可选的版本 |
| 文件 | `/browse/:id?` | 直接浏览存储源目录,点开即播,不需要建库 |
| 播放 | `/play/:fileId` | 见 [播放](playback.md) |
| 追番 | `/bangumi` | 自己追的番 |
| 设置 | `/settings` | 仅管理员 |

## 2. 首页与列表

- **全幅 Hero 剧场**:首页与详情页用背景大图 + 多层渐变遮罩,标题自动轮播、鼠标悬停暂停;
  背景有极缓的 ken-burns 位移,不会静止得像一张图。
- **横向影轨**:继续观看(带进度条与「还剩 x 分钟」)、最近添加的电影/剧集、评分最高的 Top 10
  (超大序号叠在封面上);影轨支持吸附滚动、悬停出现左右箭头。
- **海报卡**:悬停放大 + 信息浮层 + 快捷播放按钮;没有海报时用标题生成的渐变占位图,不留灰块。
- **顶栏**:在 Hero 上是透明渐变、滚动后变毛玻璃。

## 3. 文件浏览器(不建库也能看)

顶部导航的 **「文件」**:浏览任意存储源的目录,点视频就播
(同样经过决策引擎:该 302 直连就 302,iOS 播不了的自动转封装,并支持断点续播)。
不想刮削、不想整理结构时,这是最快的一条路。

也支持只建库不填 TMDB key —— 扫描后照样能播,只是没有海报和简介。

## 4. 搜「还没入库」的番剧(B 站源)

搜索框(⌘/Ctrl + K)除了搜媒体库,也会用挂了 B 站源的剧集库去搜 **B 站片库**。库里还没有的条目
显示在「B 站片库 · 未入库」那一行:点一张卡,只把这一个系列读进来,同时打开一个实时加载页,
依次显示「读取季度与剧集 → 建立剧集条目 → 匹配封面与简介」,完成后自动跳到详情页。

- 导入的是**整个系列**(同一系列的所有季度一起读),和正常扫码得到的目录结构一致,之后再扫也不会重复;
- 只走**这一个系列的子树**,不遍历整个片库;清理也只清理这次真正读过的目录,库里其它番剧不受影响;
- 片库搜索有 10 分钟缓存,并自动补上 B 站风控要求的 `buvid3`;输入不足两个字不会发请求;
- 被 B 站限流时,「B 站片库」那一行会直接提示,过几分钟再试即可。

相关 API:`GET /api/catalog/search?q=…`、`POST /api/catalog/import`、`GET /api/import/{jobId}`。

## 5. 细节与无障碍

骨架屏、图片渐入、Toast、空状态、焦点环、`prefers-reduced-motion` 降级、列表/网格视图切换。

## 7. 自己改站点的样子(编辑工具栏)

登录后打开 <http://127.0.0.1:5666/login?toolbar=1>(或者 **设置 → 站点外观 → 改登录页文案**,
登录页右下角也有一个「编辑此页」小按钮),页面右下角会出现一条浮动工具栏——和 Vercel 部署后的
"Visit with toolbar" 同一个用法:**页面本身就是编辑器**,改完立刻能看到样子。

- **文案**:标题、段落、亮点卡片、按钮文字、链接文字、登录表单的四种状态说明、页脚每一栏,
  都能直接**在页面上点着改**(点进那一行就变成可输入的文本,`{host}` 这类占位符在点进去时才显示);
  右边的面板既可以改同一批文案,也可以增删/排序亮点卡片与页脚栏目。
- **布局**:品牌面板在左还是右、两栏比例、表单宽度、圆角、背景渐变与网格的开关与浓淡、
  亮点卡片单/双列、主题色(琥珀/蓝/紫/绿/粉——只作用于登录页与页脚,不动后台其他页面)。
- **页脚**:品牌名、简介、运行状态、链接栏目(带路由候选)、播放能力、版权行。
  页脚只出现在登录后的页面上,所以在登录页打开「页脚」时面板会说明这一点,并给一个
  「改登录页底部那行小字」的入口。
- **导航**:桌面导航、手机底部标签、头像下拉菜单三份都可以改顺序、改文案、改图标、加自定义链接。
- **不会改瞎**:所有改动先是浏览器里的草稿,只有点**发布**(或 `Ctrl/Cmd + S`)才对访客生效;
  `Ctrl/Cmd + Z` 撤销、`Esc` 收起面板、眼睛图标关掉虚线标记只看效果。
  标题栏会显示「有未发布的修改」,面板底部写着上次发布的时间与操作者。
- **占位符**:`{host}` / `{version}` / `{site}` / `{year}` / `{user}`,发布后按当前访问者填充。
- **两个窗口同时改**:发布时会带上加载时的版本号,落后者收到 409,提示「有人在这期间改过」
  并自动拉取最新版本,不会把别人的改动覆盖掉。
- **恢复内置文案**:面板底部的刷新按钮(`恢复成内置文案`)清空所有已发布内容。

内容存在 `data/site.json`(随数据目录),形如 `{"revision":2,"updated_at":"…","updated_by":"admin","content":{…}}`;
`content` 为空就表示"从没发布过",前端回落到代码里内置的默认文案。服务端不校验结构,
字段的增删只发生在前端(`webui/src/site/schema.js`),所以加一条可改的文案不需要动后端。

## 8. 全屏与播放器控件

播放页的三种形态、手势、全屏锁定等细节见 [播放](playback.md) 第 7 节,
这里补充几条与全屏布局有关的:

- **全屏里的设置栏**:全屏时设置是**右侧一条栏**(手机上 `min(340px, 86vw)`),不是整屏的抽屉——
  画面还在后面,读起来是「一个面板」而不是「换了一页」;字号、芯片内边距、间距都按窗口高度
  `clamp()`,保证**不用上下翻动**就能点到所有按钮。
- **一条栏,两个面**:点「字幕」只出**字幕**(字幕轨 + 忠实排版(烧录)),点齿轮出**其余设置**
  (版本 / 音轨 / 播放速度 / 播放模式 / 画面);标题跟着换。
- **全屏**:进的是**整个播放器**,不是画面那一个元素。全屏是一层顶层(top layer),只渲染全屏元素
  自己的子树,所以把画面单独拿去全屏时,设置抽屉在顶层之外 —— 既不在屏幕上,也收不到触摸。
  现在整机全屏,链条靠 CSS 铺满,设置抽屉作为右侧浮层正常工作。
- **全屏锁定**:进入全屏后画面**左侧正中**有一个锁按钮,点一下锁定——顶部返回、控制条、进度条、
  快捷键提示全部隐藏,**并且不再是可点中的元素**,画面本身也不再响应拖动,弹窗直接不渲染;
  再点一下解锁;退出全屏自动解锁。`Esc` 始终能退出全屏。
- **全屏里的加载状态**:全屏剧场没有"下方"可用,用画面中央的转圈 + 提示卡。
  观看页(手机竖屏 / 平板)则把「正在探测媒体信息 / 正在生成分片 / 正在缓冲」做成视频下方的
  **长条进度条 + 一行文字**。
- **关于浏览器自带的视频手势**:部分安卓浏览器(以及三星浏览器)在全屏视频上自己带一层手势:
  左右滑快进/快退、右侧上下滑调音量、左侧上下滑调**亮度**。最后一条是关键证据 —— **网页没有任何
  API 能改屏幕亮度**,所以那层手势属于浏览器,网页拿不到也拦不住。想确认是不是它,换个浏览器
  (或关掉浏览器设置里的「视频助手 / 手势」)再试同一段操作即可。

设计 token 集中在 `webui/src/styles.css`,组件在 `webui/src/components/`。
